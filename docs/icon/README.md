# NickZam icon

Skinny pastel-red lightning bolt (`#FF7B7B`) on a pastel-blue background
(`#A9C6FF`).

- [icon.svg](icon.svg) — preview (same geometry as the vectors below).
- `app/src/main/res/drawable/ic_launcher_foreground.xml` — bolt vector.
- `app/src/main/res/drawable/ic_launcher_background.xml` — blue background.
- `app/src/main/res/mipmap-anydpi-v26/ic_launcher{,_round}.xml` — adaptive icons.
- `app/src/main/res/drawable/ic_stat_bolt.xml` — white bolt for the
  status-bar notification icon.
